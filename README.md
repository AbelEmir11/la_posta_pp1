# La Posta Campesina

Una página web que funciona como almacén virtual para negocios locales. Permite mostrar productos, armar pedidos y facilitar el contacto con clientes.

[Visitar la demo en vivo](https://abelemir11.github.io/la_posta_pp1/)

## Características

- Catálogo de productos
- Carrito de pedidos
- Información de horarios y zonas de delivery
- Formulario de contacto directo
- Diseño responsive (adaptado a celulares)
- pagina nosotros o ¿quienes somos?

## Tecnologías utilizadas

- HTML5
- CSS3
- bootstrap
- mayor estilismo con fotawesome para el tipo de letra
- alertas mas bonitas y llamativas con sweetalert2
- JavaScript (vanilla)
- GitHub Pages para el hosting
